ทำอะไรได้บ้าง
หาที่นั่งของฉัน: เลือกโซน แถว และเลขที่นั่งตามบัตร แล้วกล้องจะบินไปที่ที่นั่งนั้น
ดูวิวจากที่นั่ง: มีโหมด "ขนาดเท่าตาเห็น" ที่ปรับให้ขนาดบนจอเท่ากับที่ตาเห็นจริง และโหมด "มุมกว้าง" สำหรับดูรอบตัว
จำลองกล้องมือถือ: มีกรอบวิวไฟนเดอร์ตามระยะเลนส์จริงของแต่ละรุ่น เลือกวิดีโอ 16:9 หรือรูป 4:3 และถือแนวนอนหรือแนวตั้งได้
ศิลปินจำลอง: หุ่นคนสูงตามที่ตั้ง (150–195 ซม.) ย้ายไปเวทีหลัก ทางเดินกลาง หรือเวทีรองได้ และจะเดินไปตามเส้นทางบนเวที
ข้อมูลระยะ: บอกระยะถึงศิลปิน มุมที่ศิลปินกินในสายตา และในโหมดกล้องบอกว่าศิลปินสูงกี่ % ของเฟรม
โหมดคนนั่ง: ใส่คนนั่งเต็มทุกที่ เพื่อดูว่าหัวคนแถวหน้าบังแค่ไหน
กรองตามราคา: แตะราคาที่แถบล่างเพื่อไฮไลต์เฉพาะโซนราคานั้น

วิธีใช้
เปิดลิงก์ ลากนิ้วเพื่อหมุน บีบนิ้วเพื่อซูม
แตะเก้าอี้ หรือกด "หาที่นั่ง" แล้วเลือกโซน แถว และเลขที่นั่ง
กด "ดูวิวจากที่นั่งนี้" ลากนิ้วเพื่อมองรอบๆ
ครั้งแรกให้กด "ปรับเทียบจอ" เอาบัตรเครดิตหรือบัตรประชาชนทาบจอแนวตั้ง ปรับกรอบให้เท่าบัตร แล้วตั้งระยะตาถึงจอ (มือถือราว 30 ซม.) ค่านี้เก็บไว้ในเครื่องของคุณเท่านั้น
กด "กล้องมือถือ" เพื่อเลือกรุ่นและเลนส์ แล้วใช้แถบซูมหรือบีบนิ้วซูม
ใช้ปุ่ม "ศิลปินอยู่ที่" เพื่อย้ายศิลปินไปเวทีหลัก ทางเดินกลาง หรือเวทีรอง
